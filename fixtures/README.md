# Fixtures

Test inputs so the whole pipeline can run on a laptop without glasses.

- `audio/` — short WAV clips (16 kHz mono) of team members saying commands in Hindi, English and Hinglish. Name them by what's said, e.g. `hinglish_tv_youtube_kholo.wav`.
- `photos/` — JPEGs for vision tests: signs in Devanagari, a chess position, a poster, a visiting card.
- `profiles/` — a sample resume and job description for interview mode. Use made-up data, not anyone's real resume.
