# Android app

The phone app: wake word, the real-time voice session (Gemini Live), the glasses' camera (Meta Wearables SDK), the TV remote, and the settings screens (Home, Modes, Memory, Devices, AI & Keys).

Build and setup steps are in [docs/SETUP.md](../docs/SETUP.md#3-build-and-install-the-phone-app). Needs Android 14+.
